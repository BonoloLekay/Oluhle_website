# 🏡 Resort Booking Management System

A modern web-based Resort Booking Management System developed to streamline booking operations for **Oluhle Resort**. The system replaces manual booking processes with a centralized digital platform, allowing guests to book chalets, conference facilities, and spa treatments while enabling staff to efficiently manage reservations, payments, customer enquiries, and reporting.

---

## 🌐 Project Overview

Oluhle Resort previously relied on WhatsApp, phone calls, and paper records to manage reservations. As the number of guests increased, this manual process resulted in booking conflicts, lost records, slow customer response times, and inefficient reporting.

This application provides a secure and user-friendly solution that centralizes resort operations and improves the overall customer experience.

---

## 🎯 Business Objectives

The system aims to:

- Eliminate paper-based booking records
- Prevent double bookings
- Provide real-time availability
- Improve customer communication
- Centralize customer information
- Digitize payment records
- Improve reporting and decision-making
- Increase operational efficiency

## 💻 Installation

Clone the repository

```bash
git clone https://github.com/BonoloLekay/Oluhle-resort-booking-management-system.git
```

Navigate into the project

```bash
cd Oluhle-resort-booking-management-system
```

Create a virtual environment

```bash
python -m venv venv
```

Activate the virtual environment

Windows

```bash
venv\Scripts\activate
```

Install dependencies

```bash
pip install -r requirements.txt
```

Run the application

```bash
python app.py
```
